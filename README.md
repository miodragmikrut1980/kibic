# Kibic Fenster Sombor

Sajt za Kibic Fenster DOO, PVC i ALU stolarija iz Sombora.

Jedna statična stranica (`index.html`) bez build koraka. Fontovi se učitavaju sa Google Fonts.

## Pokretanje lokalno

Otvorite `index.html` u pregledaču, ili:

```
python3 -m http.server 8000
```

## Šta još treba

- Fotografije radova u galeriju (sekcija `#radovi`)
- Forma koja šalje upit na email (sada sastavlja WhatsApp poruku)
- Postavljanje na domen i osnovni SEO
